# Code map: audio-codecs

Base ed77e3c (main after cli-translate).

## What exists and is reused

- `build.zig.zon`: one lazy dependency (`sqlite`, a URL plus hash). The three new libraries
  are added the same way: url plus the hash `zig fetch` printed (in requirement-raw.md).
  `.paths` stays `build.zig`, `build.zig.zon`, `src`.
- `build.zig:31-38`: SQLite's pattern. `b.lazyDependency(...).path("")` for the source
  root, one `addTranslateC` on `src/c.h` with the include path, then `module()` adds the C
  sources with `-D` flags to the module that links libc. The new libraries follow it: their
  `.c` files and a `config.h` (or `-D` flags) compiled into one module, `src/audio.zig`,
  with its own translate-c header.
- `build.zig:40-55`: modules are wired by name (`tilla`, `r2`, `outbound.zig`, `cli`). The
  `audio` module is new and is imported by the test roots now and by `cli` in the next
  slice (one file per module rule).
- `build.zig:62-105`: every `test/*.zig` is a test root importing the named modules; the new
  test file needs `audio` in that import list.
- `src/tilla.zig`: the deterministic-output precedent (same input, same `.tilla.gz` bytes,
  so the same sha256). `publish` hashes the `.opus` into `opus_sha256` (src/cli.zig), so a
  deterministic encoder keeps a rerun of narrate on the same PCM from changing the hash.

## What doesn't exist

- No audio code, no Ogg or FLAC code, no PCM type.
- Upstream builds use autotools/CMake/meson; none run here. Each library needs its config
  written as `-D` flags or a small `config.h` generated by `b.addConfigHeader`, and a
  chosen source list (opus: fixed or float build, no SIMD intrinsics files unless
  the target has them; flac: libFLAC only, no Ogg aspect, no tools).

## Boundaries crossed

- libopus/libopusenc and libFLAC C entry points (`ope_encoder_create_callbacks`,
  `ope_encoder_write`, `ope_encoder_drain`, `FLAC__stream_encoder_*`): each returns an
  error code to map to a Zig error.
- No network, filesystem or env: the encoder takes PCM in memory and returns bytes in
  memory (narrate writes the files).
